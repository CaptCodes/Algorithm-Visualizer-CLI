# Complexity Reference

This document contains the time and auxiliary space complexity of the operations currently implemented in the project.

| Operation | Time Complexity | Auxiliary Space |
|---|---:|---:|
| Vector Traversal | O(n) | O(1) |
| Find Maximum | O(n) | O(1) |
| Find Minimum | O(n) | O(1) |
| Reverse Vector | O(n) | O(1) |
| Linear Search | O(n) | O(1) |
| Stack Push | O(1) | O(1) |
| Stack Pop | O(1) | O(1) |
| Stack Top | O(1) | O(1) |
| Queue Enqueue | O(1) | O(1) |
| Queue Dequeue | O(1) | O(1) |
| Queue Front | O(1) | O(1) |
