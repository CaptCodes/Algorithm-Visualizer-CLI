# Algorithm Visualizer CLI

A C++ command-line tool that demonstrates basic algorithms and data structure operations step-by-step.

## About the Project

Algorithm Visualizer CLI is a beginner-friendly C++ command-line project that helps visualize how basic algorithms and data structure operations work.

Instead of showing only the final result, the program displays the steps performed by an operation, making the underlying process easier to understand.

This project is being developed alongside my DSA learning journey and will be expanded as I learn more concepts.

## Current Features

- Interactive command-line menu
- Vector input and traversal visualization
- Find maximum and minimum values in a vector
- Reverse a vector step-by-step
- Linear Search visualization
- Stack operations:
  - Push
  - Pop
  - Top
  - Is Empty
- Queue operations:
  - Enqueue
  - Dequeue
  - Front
  - Is Empty
- Time and space complexity information
- Navigation between different operations through CLI menus

## Complexity

| Operation | Time Complexity | Auxiliary Space |
|---|---:|---:|
| Vector Traversal | O(n) | O(1) |
| Find Maximum | O(n) | O(1) |
| Find Minimum | O(n) | O(1) |
| Reverse Vector | O(n) | O(1) |
| Linear Search | O(n) | O(1) |
| Stack Push | O(1) | O(1) |
| Stack Pop | O(1) | O(1) |
| Stack Top | O(1) | O(1) |
| Queue Enqueue | O(1) | O(1) |
| Queue Dequeue | O(1) | O(1) |
| Queue Front | O(1) | O(1) |
